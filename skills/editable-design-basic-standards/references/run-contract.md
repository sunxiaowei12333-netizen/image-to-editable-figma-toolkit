# 运行与验收边界

普通 UI 文字的轻微字形差异优先按 [字体与视觉容差](font-visual-policy.md) 自动验收并继续；本文旧的像素一致/失败表述不覆盖已通过该规则的变化。写入范围保护、明显排版、属性及非文字变化仍按原规则处理。

## 写入前固定任务约束

记录链接目标 Page/画面 ID、实际可见范围、授权阶段、共享依赖、可写字段和字体分类，保存到任务目录。直接编辑链接目标；范围外节点及共享母组件/样式/变量只读，授权范围内实例允许安全覆盖，不 detach。仅影响授权范围内实例的本地母组件可以修改。依照当前可用的 figma-use 执行，每次最多切页一次；不为原位编辑新建 Page。

## 特殊字体与普通字体

用户要求“特殊字体不动”时，先根据用户指定、真实字族与用途列出 protected-special / ordinary / uncertain 及理由；艺术、品牌展示等专用字族按特殊字体保护。特殊字体的 family/style、字号、数值字重、行高、字距和文案保持，不为联库或按钮替换覆盖。无法分类的自定义别名保持原样，报告 uncertain，不能仅凭名称将它映射成另一字体。

普通 UI 字体仍按 Profile 规范，不把“特殊字体不动”扩成全局禁止字体规范化。加载失败本身不能证明字族特殊，也不能免除字体加载规则；必须编辑但无法加载原字体的操作记 blocked-font，只隔离相关节点和依赖族。未经证实的字体替代不执行。受保护且无需编辑的稳定文字记用户保留项，可验证其属性/几何/渲染保持，但不得宣称加载或可编辑性通过。未解决缺陷仍保留为未完成。

第一份文字快照包含 characters、fontName、fontSize、fontWeight、lineHeight、letterSpacing、区间样式/字色 key、变量与几何。不要事后用最终值补造初始值。普通字体的样式联动仍要求真实等价；若需要基础规范化，应在第一阶段先记录具体修复目标和影响范围。

## 副本与原位边界

默认 `editMode="in-place"`，边界 JSON 使用 `mode="before-after"`：`source` 和 `copy` 是兼容字段名，分别表示同一目标 ID 的操作前后快照。每个 target 保存非空 `baselineId`，两个快照的 `capturedAt` 为递增 Unix 毫秒数。检查根边界、父级/顺序及写入范围和共享依赖，不要求源/副本映射或“目标未改”。

只有用户明确要求副本时，使用 `editMode="safe-copy"`，边界 JSON 使用 `mode="source-copy"`，比较不同 ID 的真实源稿与副本，并另验源稿未改。原位编辑不依赖该模式，不为过验证器复制或伪造 ID。

## 局部受限与阶段推进

已授权连续阶段时，完成当前阶段可执行项后，按候选依赖继续。前阶段存在受限节点，不阻止与其无依赖的后阶段候选。组件候选受影响子树仍必须通过真实字体、样式、几何、血缘与像素门槛，未确认样式/回滚未恢复的节点及依赖族保持 pending。写入范围保护、边界、共享依赖或回滚可信性失败仍全局停止。

原有 P0/覆盖检查继续运行并真实报告：允许独立候选继续不等于第二阶段已通过。最终 overall=complete 仍要求本轮所有必做项通过；局部成果通过但有 pending 时为 partial。用户明确排除项记 excluded-by-user 并说明，不算修复成功。保留原来的矩阵分母，只能按写前授权缩小。

## 可回退写入和视觉验证

在任务目录冻结实际待改字段、原值、受影响节点和渲染边界（含已存在阴影）；不能失败后扩大区域。节点替换先暂存旧节点，校验后再删除；新旧字体分类和受保护属性同样进入提交前检查。无等价资产保留，不为联动率破坏特殊字体。

对已有文字，已知存在字距未知、原生渲染与写入后字形不同等风险时，先用可丢弃副本验证样式写入，包括仅写 Paint Style 的操作。先验证副本与原节点基线可比，再验证写入前后像素和排版属性；两者均通过才写正式节点，并回读正式结果。字距未知时，0 仍只是候选默认值，不能把默认规则当作像素等价证据；这条优先于旧文档中无需探针的宽泛表述。副本基线因裁剪或坐标不同不可比时改用可比上下文，未解决前保留原节点，不将其算作联库成功。已有源节点不要先写坏再依赖属性赋值恢复字形缓存。

缺失字体导致跨父级移动失败时，不用替代字体绕过。仅当用户明确要求完整复制原 Page 时，可采用原生 Page.clone 并检查映射、文字指纹与截图；这只验证复制，不证明后续文字编辑或 Auto Layout 重排可用。全页复制会带入无关内容时不采用。

首次像素差异原因不明时先做无写入重复导出对照，再按单变量诊断。真实差异不可用像素容差掩盖。一次有证据的修复仍失败则回滚并验证；回滚失败停止依赖路径。记录真实前后值和结果，不以“没有报错”推定通过。

每次只返回有界摘要和完整变更 ID；详细文字/样式数据分页，避免超过工具输出限制。正式结论由最终独立回读和阶段视觉/功能证据生成。
