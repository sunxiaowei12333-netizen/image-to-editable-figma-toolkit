# 默认沿用 Figma 字体与轻微字形差异

## 默认行为

保留 Figma 节点实际 family/style、字重、文字样式及混合区间，加载当前 Figma 工具可访问的字体。不要把本机字体安装、版本追溯或系统设置变更作为正常执行前置。组织共享字体与库里的 Text Style 是不同资产；样式名称不能证明字体文件版本。缺少某个字体只处理依赖候选，其他可执行部分继续。

本规则适用于普通 UI 文字的同字体/同字重渲染差异。用户指定的字体替换和已确认排版缺陷按原阶段授权修复；特殊标题、品牌字、书法/装饰字体以及用户要求严格保护的字形保持原保护标准，快照标记 protectedFont=true。不得把未知字体自动替换成苹方。

## 接受什么，何时回退

- 文案、字体和实际字重、字号、行高、字距、文字样式、Paint/绑定不变，文字和容器的位置/尺寸不变，无换行、基线、重叠、裁切及缺字异常；只有轻微文字轮廓或边缘像素变化：按固定 text-edge-v1 自动验收，合格时记录并继续，不逐项询问用户，也不追查字体文件版本。
- 不以 SVG 路径不同、PNG 非零差异或某个最大通道差单独判失败；字形变化也不一律称为抗锯齿。真实内容与布局仍需回读及整屏检查。
- 字重/文案/样式意外变化、文字位移/换行、明显字形异常、重叠/裁切、背景/图像/矢量/可见性变化，或者超出固定轻微规则：只修复或回退受影响族，继续独立候选；保留未完成状态和原因。不得隐藏整个实例再叠原稿、转曲/贴图、改字号凑过关或放宽本轮阈值。
- 写入范围保护、范围外共享资产或回退可信性失败才全局停止。只有明确要求副本时，源稿前后及普通复制基线须严格一致，不适用文字容差；原位编辑比较目标操作前后结果。

## 固定程序 text-edge-v1

第三阶段使用 scripts/verify_component_evidence.py；evidence.json 设置 visualPolicy="text-edge-v1"。它保持 v2 的真实文件摘要、候选覆盖、前后属性、血缘与根边界检查，仅对 final 比较增加以下固定规则，不由执行模型调数值：

1. PNG 全部来自同一 MCP exportAsync PNG SCALE=1 路径。source、baseline 比较仍为解码 RGBA 零差异。
2. final 比较的文字快照和 nodeMappings 必须覆盖对应 TEXT；preserved 字段全部相等，geometry 额外记录实际 rootX/rootY。受保护字形不使用容差。
3. 对有差异的文字，保存写前/写后 TextNode 独立透明 PNG。按 export 的实际像素包围盒在根内的整数位置，对齐到共同透明矩形：只做透明补边/必要根裁剪，不缩放、描边、模糊或移动字形。保存原始导出与补边计算记录供审查。普通文字无差异时不需要额外文字 PNG。
4. 脚本从两张文字 PNG 的 alpha>=128 字形计算一像素内外轮廓带，以及 alpha 为部分覆盖的边缘像素。只有该带内的根 PNG 差异可以考虑接受，文字框里的背景及轮廓内部不自动放行。
5. 字形 alpha 绝对误差 / 较大 alpha 总量 <=6%，墨迹 alpha 总量变化 <=3%，二值字形 IoU>=95%，按 alpha 加权 RGB 误差 <=0.5%。单项不满足即不得自动接受。颜色/字重/文字属性保持还须由真实快照证明。
6. 合格变化输出 warning 和 acceptedMinorTextDifference=true，不加入 blockers；未覆盖的差异及明显属性/布局变化仍不能通过。final 中无差异直接通过，不增加额外导出。

这些是本 Skill 的固定初始产品容差，不是 Figma 官方标准，也不是证明人眼效果的充分条件。最后仍检查真实整屏、关键文字、长文案、数字布局和组件行为。初次验收通过只代表该样本；不能宣称对所有字体都已校准。

## 文件结构补充

在 evidence.json 对应 final 图片项加入：

```json
{
  "textRegions": [{
    "beforeId": "copy-text-before",
    "afterId": "instance-text-after",
    "rect": {"x": 40, "y": 100, "width": 96, "height": 24},
    "before": {"path": "text-before-padded.png", "sha256": "actual-sha256"},
    "after": {"path": "text-after-padded.png", "sha256": "actual-sha256"}
  }]
}
```

rect 是共同文字透明 PNG 在该画面根中的实际像素矩形；不是任意文字框或整个按钮框。before/after 对应同一原文及原位页面实例；母组件预览区不冒充页面实例。将补边后的 PNG 与 rect 绑定。脚本限制矩形不得超出实际文字尺寸+4px，水平偏移<=2px，顶部差不超过字号以容纳字体 ascent 空白；实际位置与布局仍由未变的快照和最终整屏核对。特殊裁剪/混合区间若不能提供可信隔离证据，只修复或回退该候选。

计数中 acceptedMinorTextDifferences 表示已接受的变化像素，unexpectedPixelDifferences 仅表示不被允许的变化。不要把已接受的文字差异算作失败、跳过或未完成；不要把回退候选算成成功。交付简要说明接受数量及无排版异常即可，不要求同事研究字体版本。
